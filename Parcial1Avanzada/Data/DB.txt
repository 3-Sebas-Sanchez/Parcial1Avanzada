--------------------------------------------------------
 TABLA: luchador
--------------------------------------------------------
Descripción: Almacena la información principal y el
             historial de victorias de cada luchador de sumo.

Campos:
  - id_luchador    INT(11)        NOT NULL  PRIMARY KEY AUTO_INCREMENT — Identificador numérico único
  - nombre         VARCHAR(100)   NOT NULL                             — Nombre del luchador
  - peso           DECIMAL(5,2)   NOT NULL                             — Peso en kilogramos (ej: 150.50)
  - victorias      INT(11)        DEFAULT 0                            — Número de combates ganados

--------------------------------------------------------
 SCRIPT DE CREACIÓN
--------------------------------------------------------
Ver archivo: luchadores.sql

El script incluye:
  1. Configuración de zona horaria y compatibilidad.
  2. Creación de la tabla          (CREATE TABLE `luchador`)
  3. Definición de llaves primarias (ALTER TABLE `luchador` ADD PRIMARY KEY)
  4. Configuración autoincremental (ALTER TABLE `luchador` MODIFY `id_luchador`...)
